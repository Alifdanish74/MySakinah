# MySakinahPro Admin design direction

## Design read

Reading this as a membership-submission admin dashboard for staff, in the Islamic family-protection identity of MySakinahPro, with ENERGY 1, RHYTHM 2, and MOTION 1.

## Direction

- The product owner requested an Islamic design and named [mysakinahpro.com.my](https://www.mysakinahpro.com.my/) as the reference.
- Use the public site's green, white, and deep navy as the brand cues. The light theme is the default because it matches the reference and supports dense record review; a working dark theme remains available.
- Keep Inter because it is already used by the app and stays legible in data-heavy screens.
- Use role-specific icons to identify actions and destinations; adjacent text stays primary so icon shape is never the sole carrier of meaning.
- Give submissions and module navigation the visual priority. Use a restrained green keyline as the repeated identity motif, drawn from the site's green mark and calls to action.
- Do not invent a logo, calligraphy, religious ornament, people, testimonials, or data. Use existing product text and live records only.
- Keep motion to dialog state changes and subtle hover feedback so record review stays calm and predictable.

## Decision notes

- Solid surfaces and green keylines carry the reference site's identity without competing with dense record content.
- Module cards are links because each card represents a real destination, while the overview metrics use compact panels to make the current totals easy to scan.
- On narrow screens, keep the full record schema inside its own horizontal scroller rather than widening the page.
- Reserve shadows and backdrop blur for layered dialogs; keep ordinary cards flat so the content hierarchy stays clear.
- Hide the nonessential profile avatar on phones so the page title and theme/sign-out controls remain within the viewport.
- Distinguish membership categories with the prior blue, pink, green, and amber color mapping so staff can scan category data quickly in either theme.
